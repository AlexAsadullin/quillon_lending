# Документы автосервиса

Рабочий архив: исходные материалы, по которым пишется сайт. **На сайт не публикуется**
(сборка копирует в `dist/` только `css/`, `js/`, `assets/`) и **не попадает в git** — репозиторий
публичный, см. `.gitignore`. Храните здесь оригиналы, а на сайт выносите только то, что можно показывать всем.

| Папка        | Что класть                                                        |
|--------------|-------------------------------------------------------------------|
| `garantiya/` | условия гарантии, образец гарантийного талона                     |
| `rekvizity/` | реквизиты: ИНН, ОГРН, юридический адрес — нужны для `privacy.html` |
| `foto/`      | исходники фото сервиса, мастеров, оборудования                    |

Фото, которое должно появиться на сайте, — уменьшить, сохранить в `assets/img/` и подключить в шаблоне.
