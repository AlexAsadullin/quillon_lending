# Контент сайта

Все факты сайта — здесь. HTML руками не правится: поменяли файл → `node scripts/build.mjs` →
готовый сайт в `dist/`. Vercel запускает сборку сам при каждом пуше в `main`.

Источник фактов — документы клиента в `Архив/`: прайс (п. 1–14), регламент и договор.
Переписка — не источник. Чего нет в документах — «[уточнить у владельца]» и строка в `probely.md`.
У каждого JSON есть поле `_source` — откуда взяты данные.

| Файл                   | Что в нём                                                                  |
|------------------------|----------------------------------------------------------------------------|
| `prices.json`          | **единственное место цен**: работы п. 1–11 и условия п. 12–14              |
| `services/<slug>.json` | услуга = страница `/uslugi/<slug>/`: какие пункты прайса и условия к ней относятся |
| `terms.json`           | гарантия, оплата, выдача, отказ и возврат                                   |
| `faq.json`             | вопросы и ответы, у каждого — источник                                     |
| `home.json`            | тексты главной и заголовки разделов                                        |
| `site.json`            | название, адрес сайта, телефон, адрес, режим работы `schedule` (из него — часы на сайте, слоты записи, микроразметка) |
| `probely.md`           | чего нет в фактуре — список для владельца                                  |
| `docs/`                | документы автосервиса — **не публикуются и не попадают в git**             |

## Цены

Цена пишется только в `prices.json`. В текстах — подстановки, сборка заменит их на значения:

| Подстановка                 | Станет                                      |
|-----------------------------|---------------------------------------------|
| `{price.7}`                 | `12 000 ₽` — цена работы п. 7               |
| `{cond.13}`                 | `+20 %` — краткое значение условия п. 13    |
| `{condText.14}`             | полный текст условия п. 14                  |
| `{terms.guarantee.works}`   | `6 месяцев` — из `terms.json`               |

Владелец поменял цену — правка в одном месте, все страницы обновятся.

## Услуга

```json
{
  "slug": "grm",                     // адрес страницы: латиница, цифры, дефис
  "order": 3,                        // порядок в списках
  "title": "Ремень ГРМ",             // карточка, меню подвала, форма записи
  "heading": "Замена ремня ГРМ",     // заголовок страницы
  "points": [7],                     // пункты прайса — работы этой услуги
  "conditions": [12, 13],            // условия; 12 и 13 обязательны для всех услуг
  "cta": "Записаться на замену ГРМ"  // кнопка на странице услуги
}
```

Новая услуга — новый файл: страница, карточка, пункт формы, подвал и `sitemap.xml` появятся сами.
Сборка проверит, что каждая работа прайса относится ровно к одной услуге.

## Сборка не пропустит

«от N» в ценах, «под ключ», отзывы, «опыт», «лет на рынке», сроки работ («за 3 часа»),
ссылку на несуществующий пункт прайса. Поля, начинающиеся с `_`, — служебные заметки, не проверяются.
