# Шестерёнка — лендинг автосервиса в Москве

Одностраничный статичный сайт автосервиса «Шестерёнка» с формой «Заказать звонок».
Чистые HTML, CSS и JavaScript: без фреймворков, сборщиков и зависимостей.

Дизайн-концепция — «технический чертёж»: миллиметровка, размерные линии, шестерёнка,
которая вращается при прокрутке, и форма заявки в виде отрывного заказ-наряда
со штампом «Принято».

## Запуск

```bash
git clone https://github.com/AlexAsadullin/quillon_lending.git
cd quillon_lending
python3 -m http.server 8080
```

Откройте http://localhost:8080.

## Структура

```
index.html          — лендинг
privacy.html        — политика обработки персональных данных (152-ФЗ)
css/style.css       — стили; цвета, шрифты и отступы — токены в :root
js/config.js        — настройки (адрес обработчика формы)
js/main.js          — меню, анимации, маска телефона, отправка формы
assets/favicon.svg  — иконка
.claude/CLAUDE.md   — правила кода, безопасности и дизайна для разработки
```

## Форма заявки

Сайт статичный, поэтому заявки отправляются на внешний обработчик: webhook n8n,
свой бэкенд, Formspree и т.п. Обработчик принимает `POST` с JSON:

```json
{
  "name": "Иван",
  "phone": "+79161234567",
  "car": "Kia Rio 2018",
  "consent": true,
  "page": "https://example.ru/",
  "sentAt": "2026-10-09T10:00:00.000Z"
}
```

Подключение:

1. Укажите URL обработчика в `js/config.js` → `FORM_ENDPOINT`.
2. Добавьте домен обработчика в `connect-src` политики CSP в `<head>` файла `index.html`.

Пока `FORM_ENDPOINT` пустой, на `localhost` форма работает в демо-режиме и никуда
не отправляет данные. На боевом домене она сообщает, что заявка не отправлена,
и показывает номер телефона.

> Токены ботов, ключи API и другие секреты в `js/config.js` класть нельзя:
> файл скачивает каждый посетитель. Секреты хранит обработчик.

Защита формы на клиенте: валидация полей, скрытое поле-ловушка для ботов,
не больше одной отправки в 60 секунд, обязательное согласие на обработку
персональных данных. Обработчик на сервере должен проверять данные повторно.
