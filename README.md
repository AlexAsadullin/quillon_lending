# Шестерёнка — лендинг автосервиса в Москве

Одностраничный статичный сайт автосервиса «Шестерёнка» с формой «Заказать звонок».
Чистые HTML, CSS и JavaScript: без фреймворков, сборщиков и зависимостей.

Дизайн-концепция — «технический чертёж»: миллиметровка, размерные линии, шестерёнка,
которая вращается при прокрутке, и форма заявки в виде отрывного заказ-наряда
со штампом «Принято».

## Запуск

```bash
git clone https://github.com/AlexAsadullin/quillon_lending.git
cd quillon_lending
python3 -m http.server 8080
```

Откройте http://localhost:8080.

## Структура

```
index.html          — лендинг
privacy.html        — политика обработки персональных данных (152-ФЗ)
css/style.css       — стили; цвета, шрифты и отступы — токены в :root
js/config.js        — настройки (адрес обработчика формы)
js/main.js          — меню, анимации, маска телефона, отправка формы
assets/favicon.svg  — иконка
n8n/                — воркфлоу n8n для приёма заявок
.claude/CLAUDE.md   — правила кода, безопасности и дизайна для разработки
```

## Форма заявки

Сайт статичный, поэтому заявки отправляются на внешний обработчик: webhook n8n,
свой бэкенд, Formspree и т.п. Обработчик принимает `POST` с JSON:

```json
{
  "name": "Иван",
  "phone": "+79161234567",
  "car": "Kia Rio 2018",
  "problem": "Стучит спереди справа на кочках",
  "consent": true,
  "page": "https://example.ru/",
  "sentAt": "2026-10-09T10:00:00.000Z"
}
```

### Заявки → n8n → Google Таблица

Готовый воркфлоу: [n8n/shesterenka-leads.json](n8n/shesterenka-leads.json).

```
Webhook (POST) → проверка и очистка → данные корректны?
                                       ├─ да  → строка в Google Таблицу → ответ 200 { ok: true }
                                       └─ нет → ответ 400 { ok: false, error }
```

1. **Таблица.** Проще всего — загрузить готовый шаблон
   [n8n/shesterenka-leads-template.xlsx](n8n/shesterenka-leads-template.xlsx) в Google Диск
   и открыть его как Google Таблицу (*Файл → Сохранить как Google Таблицу*).
   В нём уже есть выпадающий список статусов и подсветка новых заявок. Или создайте таблицу
   вручную: лист `Заявки` и строка заголовков ровно такая:

   | Имя | Телефон | Марка | Что случилось | Время | Статус |
   |-----|---------|-------|---------------|-------|--------|

   В «Статус» новые заявки приходят со значением `Новая`. Для удобства сделайте
   на этом столбце раскрывающийся список: Новая / Перезвонили / Записан / Отказ.
2. **Импорт.** В n8n: *Workflows → Import from File* → `n8n/shesterenka-leads.json`.
3. **Узел «Строка в таблицу».** Подключите учётные данные Google Sheets (OAuth2)
   и вставьте ссылку на свою таблицу вместо `ВСТАВЬТЕ_ID_ТАБЛИЦЫ`.
4. **Активируйте** воркфлоу и скопируйте **Production URL** из узла «Заявка с сайта»
   (вида `https://<ваш-n8n>/webhook/shesterenka-lead`, не `/webhook-test/`).
5. **Сайт.** Вставьте этот URL в `js/config.js` → `FORM_ENDPOINT`, а origin n8n
   (`https://<ваш-n8n>`) добавьте в `connect-src` политики CSP в `<head>` файла `index.html`.
   Задеплойте.

Что делает воркфлоу:

- повторно проверяет имя, телефон (`+7` и 10 цифр) и согласие на обработку данных;
  невалидная заявка в таблицу не попадает;
- обрезает длину полей и убирает управляющие символы;
- ставит время приёма по Москве со стороны сервера;
- пишет значения в режиме RAW, поэтому текст вида `=ФОРМУЛА(...)` из формы
  не выполнится в таблице;
- принимает запросы только с `https://quillonlending.vercel.app` (CORS, настройка
  *Allowed Origins* в узле «Заявка с сайта»). Для локальной отладки временно
  добавьте туда `http://localhost:8080` через запятую.

Пока `FORM_ENDPOINT` пустой, на `localhost` форма работает в демо-режиме и никуда
не отправляет данные. На боевом домене она сообщает, что заявка не отправлена,
и показывает номер телефона.

> Токены ботов, ключи API и другие секреты в `js/config.js` класть нельзя:
> файл скачивает каждый посетитель. Секреты хранит обработчик.

Защита формы на клиенте: валидация полей, скрытое поле-ловушка для ботов,
не больше одной отправки в 60 секунд, обязательное согласие на обработку
персональных данных. Обработчик на сервере должен проверять данные повторно.

- [ ] Подключить обработчик формы (см. выше)
